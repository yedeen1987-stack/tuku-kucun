# 本地识图服务怎么接进来

## 先说一个必须知道的限制

你的架构图里有这么一条：

```
网页【拍照找货】 ──→ 【本地识别】
```

**这条线直接连是跑不通的。**

图库网页是 Cloudflare 上的 HTTPS 页面，本地识图服务是公司内网的 HTTP
（比如 `http://192.168.1.50:8000`）。所有现代浏览器都会把
「HTTPS 页面去请求 HTTP 地址」当成混合内容（mixed content）直接拦掉，
而且错误提示很不明显——看起来就像「点了没反应」。

手机、电脑一样拦。这不是配置问题，是浏览器安全策略，绕不过去。

## 推荐做法：Cloudflare Tunnel

你已经全套在 Cloudflare 上了，这个最顺。公司电脑上跑一个 `cloudflared`，
本地服务就有了一个真正的 HTTPS 地址。

```
# 公司电脑上（Ubuntu 服务器）
cloudflared tunnel login
cloudflared tunnel create textil134-match
cloudflared tunnel route dns textil134-match match.你的域名
```

配置文件 `~/.cloudflared/config.yml`：

```yaml
tunnel: textil134-match
credentials-file: /root/.cloudflared/<隧道ID>.json
ingress:
  - hostname: match.你的域名
    service: http://127.0.0.1:8000
  - service: http_status:404
```

跑起来：

```
cloudflared tunnel run textil134-match
```

做成开机自启：

```
cloudflared service install
```

这样网页就能正常调用 `https://match.你的域名/search`，
而且**你在店里、在家、在路上都能用**，不用连公司 Wi-Fi。

### 两件必须做的事

**1. 一定要加保护。** 隧道地址是公网可达的。不加保护等于把你的识图服务
和整个图库特征索引开放给全世界。两个办法：

- Cloudflare Access（零信任，按邮箱放行）
- 或者最简单：识图服务自己校验一个 `Authorization: Bearer <token>`

**2. 公司电脑关机 = 拍照找货不可用。** 这个要接受，或者准备一台常开的机器。

## 备选做法：Worker 当队列

不想暴露本地服务的话：网页把照片传给 Worker 存进 R2，本地电脑轮询取任务，
算完把结果推回 Worker，网页轮询拿结果。

好处是完全不用暴露本地服务。代价是要多写一套队列，而且慢 1–2 秒。

## 关于「断网还能用」

你架构里第十九条写着：

> 本地识图不依赖互联网，即使外网断了，拍照 → 找款 → 找楼层仍然能工作

**外网断了这套是不能工作的。** 因为货位在线上图库、拣货单也在线上建，
断网时你连那个网页都打不开。

我觉得这可以接受——Cloudflare 的可用性比公司宽带高得多，真出问题
多半是宽带断了而不是 Cloudflare 挂了。但**别在设计里当成能离线**，
不然哪天真断网你会以为是系统坏了。

真正需要离线的是**工人手机端**，那个已经做好了：拣货单和照片会缓存，
点「已拿」先排本地队列，有信号自动补发。

## 识图服务应该长什么样

一个最小的 HTTP 服务，两个接口：

```
POST /index            # 增量：把新图片加进特征索引
POST /search           # 拍照找货：传一张图 + 面料，返回 Top 3
```

`/search` 的返回建议长这样，和网页那边好对接：

```json
{
  "candidates": [
    {"code": "YXS10237", "score": 0.94},
    {"code": "YXS10231", "score": 0.82},
    {"code": "YXS10255", "score": 0.76}
  ]
}
```

**网页拿到 code 之后自己去图库查货位**，识图服务不需要知道货位，
也不需要连数据库。职责越窄越好维护。

### 模型选择

- 用 **DINOv2**，不要用 CLIP。布料纹理上 DINOv2 明显更好。
- 向量索引用 faiss 或者 sqlite-vss，几千到几万张都够。
- 再叠一层颜色直方图做二次排序，能压掉一部分素色误判。
- 全部在 CPU 上跑得动，不需要显卡。

### 按面料缩小范围

图库里面料是**从款号前缀自动推导**的（`code_rule` 表：YXS → crepinho，
YXZ → Duna Amassado）。所以「只搜 Crepinho」实现上就是「只搜 YXS 开头的款号」，
在索引里加个 metadata 过滤就行。

### 素色布是这套方案的死角

一块黑色 Crepinho 和一块黑色 Duna，照片上完全一样，识图必然失败。

**必须有不依赖识图的兜底**：相似度低于某个阈值时，自动切到
「按面料 + 颜色列出候选让你点选」。素色在布料库存里占比通常不低，
这不是可选项。
